# Vanguard Engineering Group — Website

Sito istituzionale di Vanguard Engineering Group. Infrastruttura AI per PMI italiane.

## Stack

- Next.js 14 (App Router) + TypeScript strict
- TailwindCSS 3.4
- Framer Motion (animazioni minime)
- React Hook Form + Zod
- Inter + Fraunces (next/font)

## Sviluppo locale

```bash
npm install
npm run dev
```

Apri http://localhost:3000.

## Script

- `npm run dev` — server di sviluppo
- `npm run build` — build di produzione
- `npm run start` — avvia il server di produzione
- `npm run lint` — esegue ESLint

## Struttura

```
app/                Pagine (App Router)
components/         UI: layout, sections, forms
lib/                Contenuti, SEO, utility
public/             Asset statici
```

Tutto il copy utente è in italiano. Codice e commenti in inglese.
